# 🍽️ TasteHub Restaurant Management System

TasteHub is an Oracle APEX-based Restaurant Management System designed to organise and manage restaurant operations through a web-based application.

## 📌 Project Overview

This project was developed using Oracle APEX and Oracle Database. The application provides a structured interface with navigation, authentication, and dedicated management pages.

The exported application contains:
- **18** application pages
- **42** regions
- **9** page items
- **6** processes
- **6** buttons
- Shared navigation and security components

## 🛠️ Technologies Used

- Oracle APEX
- Oracle Database
- SQL
- PL/SQL
- HTML and CSS (where applicable within the APEX application)

## ✨ Application Components

The exported application includes:

- Application navigation menus
- Breadcrumb navigation
- Authentication using Oracle APEX Accounts
- Authorization configuration
- Shared LOVs (List of Values)
- Application theme and UI components
- Supporting objects included in the export

## 🚀 Installation and Setup

1. Sign in to your Oracle APEX workspace.
2. Open **App Builder**.
3. Select **Import**.
4. Upload `f121374.sql`.
5. Follow the import wizard.
6. Install the application.
7. Run the application from App Builder.

**Note:** The export was generated from Oracle APEX 26.2.1. Importing it may require a compatible APEX environment and access to the appropriate database schema.
